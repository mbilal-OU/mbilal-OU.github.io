SAIL-HPC is a deterministic training model for Slurm and scientific HPC workflows. Learn, simulate, diagnose, revise and build confidence before using a real cluster.

◎
This is a deterministic training model.

SAIL-HPC simulates selected Slurm behavior in a reproducible environment. It does not run real jobs or consume real cluster resources.

⌘

    SAIL-HPC
    How this environment works
    SAIL-HPC is a browser-only deterministic educational scheduler model. It is Slurm-focused, unaffiliated with SchedMD, and does not execute Python, R or scientific software.
    • Learn concepts through guided lessons.
    • Bring your own pipeline or use scientific scenarios.
    • Build and export ordinary Slurm scripts.
    • Observe modeled scheduler/resource consequences.
    • Use assessment mode for independent practice.
    No credentials · no backend execution · no hidden telemetry.
